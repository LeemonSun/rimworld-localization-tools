# RimWorld Localization Tools

Модуль памяти переводов из рабочего проекта локализации RimWorld. На вход получает каталог строк. Сверяет их с проверенными переводами в SQLite и формирует JSON-партии для новых или изменённых строк. Команда check проверяет идентификаторы, подстановки, переносы и крайние пробелы в ответе переводчика.

## Запуск

Нужен Python 3.10 или новее. Внешних библиотек нет.

```text
python conveyor.py selftest
python conveyor.py remember
python conveyor.py prepare examples/catalog.json --package example.mod --out out
```

В примере одна строка берётся из памяти, вторая попадает в новую партию. База создаётся в state при запуске. В examples используются учебные строки. Извлечение строк из игры и сетевой перевод выполняются отдельными инструментами рабочего проекта.
